Programme effect on modern contraceptive use, robust to specification

Estimate stable across a simple 2x2 model and a model with individual covariates and state fixed effects (clustered SE by state). Baseline treatment–control gap was small and statistically insignificant (p = 0.57), supporting the parallel-trends assumption.

State-level detail

Every treatment state moved up; every control state was roughly flat — the pattern is consistent, not driven by one outlier state.
